Poubelle synchronisée

Sans jeton, la poubelle reste dans ce navigateur (perdue si tu vides le cache, différente sur chaque appareil). Avec un jeton, elle est enregistrée dans le dépôt GitHub : partagée entre tes appareils, jamais perdue.

Créer le jeton : GitHub → Settings → Developer settings → Fine-grained tokens → Only select repositories : veille-hightech → Repository permissions → Contents : Read and write. Le jeton reste dans ce navigateur, il n'est envoyé qu'à api.github.com.
